# v26.2.01 Description:
## 1 New `ver` interface
We added new `ver` interface and additional information.
- **Architechture:** x86 (32-bit)
- **Boot device:** Floppy (cl_os.img)
- **Data Disk:** hdd.img (FAT32)
- **Memory:** 64MB
- **Date:** Show your date
## 2 New `GUI` interface
### Intro
We've dropped the old VGA text mode and moved to a real graphical interface using **VBE mode**.
The new GUI runs at $1024\times 768$, which gives us a lot more room to display things and move around. We've added **$5$ icons** to the desktop, each representing a different app: **Files, Editor, Snake, Terminal, and Toolbox**. Every app gets its **own window**, and windows support **stacking, moving, and free resizing**.
Here's what each app does:
- **Editor:** open it and just start typing. Hit `F2` to save.
- **Files:** shows all your files and where they're stored. You can also open - **Folders:** and browse what's inside.
- **Snake:**  opens a game window and you can play Snake right away.
- **Terminal:**  a light-themed terminal, also in a window. You can type commands normally, though the text rendering can look a bit off because of the scaling, like the ASCII art in the ver screen.
- **Toolbox:** a toolbox with two tools for now. More might come later.

### Issues
**Screen flickering** is pretty noticeable. This is because we didn't build it with multitasking, so redraws are happening the hard way.
**Too many windows open = lag**. Performance drops once you pile up a bunch of windows.
