# v26.1.02 Description: Scrolling and Clock
## 0 Update Standard Introduction
This document is the standard update description, and the version number follows the format `Year.Version.Minor` Version.
This is the first standard update of Cl_OS, and every future update will follow the standard of this update.
The first version (initial version) is `v26.1.01`, and the update description can be found in the README document on GitHub.
**This section will be removed in the next update.**

## 1 Scrolling Screen Effect
In the main interface CLI of `v26.1.01`, users cannot scroll/browse the screen in any way.
In `v26.1.02`, the **`up` and `down` keys can be used to control the screen**.
Pressing the `up` key once scrolls the screen up by one line; if it is already at the top, the signal is considered invalid.
The same applies to the `down` key.

## 2 Clock 
In `v26.1.02`, a **variable clock is made**, and this clock is a process.
When the user enters `run time.bin`, the clock starts in the lower right corner of the screen (CLI; **if the user enters the UI, this program is forcibly closed**), and ticks with time (24-hour format, step length is seconds).
The time format must include leading zeros. The specific format is:

```
HH:MM:SS UTC
YYYY-MM-DD
```

The time standard follows UTC (UTC+0), is accurate to the second, and it could change constantly (step length is seconds).
The user can also end the process by entering `kill (PID)`.

## 3 Patches and Fixes
In v26.1.02, **shift mappings for all keys are added.** Pressing shift while pressing a key can turn it into a symbol/uppercase letter.
**A `CAPS` key is added.** If the `CAPS` key is pressed, all characters currently input should be uppercase.
**A `TAB` key is added.** Pressing `TAB` once is equivalent to pressing the spacebar 4 times.
