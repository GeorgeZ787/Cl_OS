# ChlorineOS（Cl_OS）系统介绍

## 1. 项目概览

ChlorineOS（仓库名 Cl_OS）是一个面向学习和实验的 32 位 x86 操作系统原型，主要在 QEMU 中运行。它用 NASM 编写 BIOS 引导代码，用 freestanding C 实现内核，并提供可交互的命令行、FAT 文件系统访问、简易进程管理，以及一个可从命令行进入的 VBE 图形桌面。

系统设计重点是保留直接、易观察的启动流程：启动后先进入 VGA 文本命令行；用户输入 `gui` 后，系统才切换到图形模式。桌面退出时返回原有文本命令行，之后可以输入 `shut` 关闭 QEMU 虚拟机。

Cl_OS 仍是一个小型实验系统，并不等同于具有完整硬件抽象、内存保护、用户权限、现代桌面环境或 POSIX 兼容性的通用操作系统。

## 2. 主要功能

- BIOS 软盘引导，进入 32 位保护模式并运行内核。
- VGA 文本命令行，以及从命令行主动切换到 VBE 桌面的能力。
- 1024 × 768、24 位线性帧缓冲桌面；支持鼠标和键盘操作。
- 最多同时显示 5 个可移动、可调整大小的应用窗口。
- FAT32 硬盘访问，包括浏览目录、创建目录、读写文件等操作。
- 简易文本编辑器、Snake 游戏、图形终端、计算器和 RTC 时钟/日历。
- 基础的程序启动、进程列表和进程终止接口。
- Makefile 自动创建构建目录；运行目标会在缺少 `hdd.img` 时创建 FAT32 硬盘镜像，并保留已存在的镜像。

## 3. 从开机到关机

### 3.1 启动路径

启动软盘上的代码按以下顺序运行：

1. BIOS 将软盘第一个扇区加载到 `0x7C00`，执行 `boot/boot.asm`。
2. 引导扇区从软盘读取 loader 和内核。loader 放在第 2 个扇区，内核从第 3 个扇区开始，加载到物理地址 `0x10000`。
3. `boot/loader.asm` 检查机器是否提供所需的 VBE 模式信息，并把 BIOS 字体数据复制到低端内存，供图形界面绘制文字使用。此时它只检查图形能力，不切换显示模式。
4. loader 设置 GDT、打开 A20 并进入 32 位保护模式，随后跳到内核入口。
5. 内核初始化 BSS、键盘、基本内存和磁盘，尝试挂载 FAT32，然后进入 VGA 文本命令行。
6. 在命令行输入 `gui` 后，内核通过 BIOS 视频服务切换到 VBE 帧缓冲模式，启动桌面事件循环。
7. 选择桌面上的 **EXIT TO CLI** 后，系统恢复 VGA 文本模式、显示页和光标，并返回命令行。输入 `shut` 或 `shutdown` 可请求 QEMU 关机。

因此，启动界面是文本 CLI，而不是图形桌面；VBE 仅在用户启动 GUI 时启用。该引导流程依赖 BIOS 兼容的启动方式和可用的 VBE 模式信息。

### 3.2 常用操作流程

```text
开机
  └─ VGA 文本命令行
       ├─ 输入 help 查看命令
       ├─ 输入 gui 进入桌面
       │    ├─ 打开应用窗口并操作
       │    └─ 选择 EXIT TO CLI 返回文本命令行
       └─ 输入 shut 关闭虚拟机
```

## 4. 图形桌面

### 4.1 桌面与窗口操作

桌面分辨率为 1024 × 768，像素格式为 24 位 VBE 线性帧缓冲。屏幕左侧排列应用图标，底部有 START 和 **EXIT TO CLI** 区域。

- 单击应用图标打开相应窗口。
- 按住窗口标题栏并移动鼠标，可拖动窗口。
- 拖动窗口四角，可改变窗口宽度和高度。
- 单击标题栏右侧的关闭按钮，或在窗口激活时按 `Esc`，可关闭活动窗口。
- 单击已有窗口可将其置于前景；窗口重叠时，可通过点击其可见区域切换焦点。
- 键盘方向键可在桌面图标间移动焦点，按 `Enter` 打开选中的图标；也可用鼠标操作。
- 同时最多有 5 个窗口；达到上限后，需先关闭窗口再打开其他应用。

桌面上的窗口由内核统一保存状态并在同一个图形事件循环中处理输入。窗口可并排或重叠使用，但这不代表每个窗口都有独立进程或独立 CPU 调度。

### 4.2 Files

Files 窗口显示 FAT32 当前目录中的条目，并提供返回父目录的入口。目录和文件由不同颜色区分；文件列表可显示文件大小。选择子目录可进入该目录，选择文件会打开一个新的 Editor 窗口。

当前图形列表最多显示 20 个目录项。显示名称受当前 FAT32 短文件名处理能力限制；Files 和命令行共享同一个 FAT32 当前目录，因此在一个界面中改变目录会影响另一个界面的目录上下文。

### 4.3 Editor

Editor 窗口提供独立的文本缓冲区。可以从 Files 打开已有文件，也可以直接打开空白编辑器：

- 方向键移动插入位置；字母、数字和常用可打印 ASCII 字符可输入。
- `Enter` 插入换行，`Backspace` 删除光标前的字符。
- 对已有文件按 `F2` 保存。
- 对空白编辑器按 `F2`，输入文件名并按 `Enter`，创建并保存文件。
- 文本缓冲区容量为每个窗口最多 899 字节。

各 Editor 窗口的编辑内容相互独立。关闭窗口不会保存未保存的内容，也不会弹出未保存确认；重要修改请先按 `F2` 保存。

### 4.4 Snake

Snake 在独立窗口内运行，方向键控制移动。吃到食物后分数增加、蛇身增长；撞到边界或蛇身后游戏结束。按 `Enter` 可重新开始。

Snake 在桌面事件循环中逐步更新，不会占用一个阻塞式全屏界面；但它不是独立的后台进程，也没有独立暂停/恢复机制。

### 4.5 Terminal

Terminal 提供窗口化命令输入和输出，可输入一行命令并按 `Enter` 执行。输出在窗口内滚动保留；每个 Terminal 窗口有自己的文本缓冲区，缓冲区有限，较早的完整输出行可能会被移除。

图形 Terminal 使用内核现有的命令表，但并不是完整的终端仿真器：不提供 shell 管道、命令重定向、历史记录、多个命令参数解析、TTY/伪终端或任意程序的键盘输入。需要交互输入、切换显示模式、直接操作 VGA 显示或可能阻塞的操作，请回到 VGA CLI 执行。`help` 会列出系统命令，但不代表每条命令都适合在图形 Terminal 中使用。

### 4.6 Toolbox

Toolbox 包含两项小工具：

- **Calculator**：输入两个数和一个 `+`、`-`、`*` 或 `/` 运算符组成的表达式，然后按 `Enter`。计算采用定点数表示，结果显示三位小数；除数为零时会报告错误。
- **Clock and calendar**：选择时钟选项后显示从 RTC 读取的日期和时间。按任意键返回 Toolbox 菜单。

## 5. VGA 命令行

开机命令行通过键盘输入命令。输入 `help` 可查看当前命令表。可用命令如下：

| 命令 | 用途 |
| --- | --- |
| `help` | 显示已注册命令 |
| `ver` | 显示系统版本和构建信息 |
| `ls` | 列出当前 FAT32 目录 |
| `cd <路径>` | 切换当前目录；不带路径时显示当前路径 |
| `mk <目录名>` | 创建目录 |
| `cat <文件名>` | 将文件内容显示在终端 |
| `new <文件名>` | 创建新文件 |
| `edit <文件名>` | 在文本模式编辑器中编辑文件 |
| `rm <文件名>` | 删除文件 |
| `run <程序名>` | 尝试加载并运行 FAT32 上的程序 |
| `ps` | 显示进程信息 |
| `kill <PID>` | 终止进程；也支持停止 `time.bin` 时钟服务 |
| `di` | 显示磁盘和分区信息 |
| `gui` | 切换到图形桌面 |
| `snake` | 在文本模式运行 Snake |
| `col <背景色前景色>` | 设置 CLI 颜色；例如 `col 1A` |
| `toolbox` | 在文本模式打开 Toolbox |
| `mem` | 显示当前内存功能状态 |
| `testmem` | 运行简单的内存测试命令 |
| `cls` | 清屏 |
| `shut`、`shutdown` | 请求关闭 QEMU 虚拟机 |

文件和进程命令依赖相应设备或文件系统成功初始化。`run` 的可运行文件格式及兼容性取决于内核程序加载器；这不是完整的 ELF/Linux 程序环境。

## 6. 文件系统、磁盘与进程

### 6.1 FAT32 数据盘

QEMU 以软盘镜像 `cl_os.img` 启动系统，并以硬盘镜像 `hdd.img` 提供数据盘。运行目标会在 `hdd.img` 不存在时创建 32 MiB FAT32 镜像；已存在时不会因普通的 `make run` 被自动重新格式化。

内核启动后尝试挂载 FAT32，并提供目录导航、列表、读文件、创建/覆盖文件、删除文件和创建目录等操作。使用 `rm`、编辑器保存或其他写入命令会修改数据盘内容；需要保留数据时，请先备份 `hdd.img`。

### 6.2 进程管理

内核包含一个简单进程管理器，进程表最多容纳 16 个条目，并提供创建程序、启动服务、列出进程、调度/让出 CPU 和终止进程等接口。它属于操作系统实验功能，不提供现代系统中的完整进程隔离、权限控制、虚拟内存或稳定的兼容性保证。桌面窗口不等于进程表中的进程。

## 7. 构建与运行

### 7.1 环境

项目主要面向 Ubuntu 22.04（包括 WSL）和 QEMU。需要 GNU Make、支持 `-m32` freestanding 编译的 GCC、NASM、GNU binutils 中的 `ld`、FAT 镜像工具 `mkdosfs`，以及 QEMU x86 系统模拟器。若 GCC 缺少 32 位编译支持，需要安装对应的 multilib 工具链。

在 Ubuntu 上可安装常用工具：

```bash
sudo apt update
sudo apt install build-essential gcc-multilib nasm binutils dosfstools qemu-system-x86
```

### 7.2 构建与启动

在仓库根目录运行：

```bash
make
make run
```

`make` 会生成 `build/` 下的中间文件和软盘镜像 `cl_os.img`。`make run` 会启动 QEMU：软盘作为启动设备、`hdd.img` 作为数据硬盘，并通过 VNC 提供画面。默认连接地址为：

```text
localhost:5901
```

使用 TigerVNC 或其他 VNC 客户端连接。启动完成后，在看到的 VGA 文本 CLI 中输入 `gui` 进入桌面。按桌面上的 **EXIT TO CLI** 返回 CLI，输入 `shut` 关闭虚拟机。

仅重新构建时可运行：

```bash
make clean
make
```

`make clean` 会删除构建目录中的二进制中间文件和 `cl_os.img`，但不会删除 `hdd.img`。重新构建后再次运行 `make run` 即可。请注意，`cl_os.img` 是启动介质；用户文件应保存在 FAT32 数据盘 `hdd.img`，而非启动软盘镜像中。

### 7.3 构建容量限制

启动代码按软盘 CHS 区段读取内核，当前最多加载 124 个扇区，即 63,488 字节。Makefile 在链接后检查内核大小，超出限制时构建失败。增加内核功能时应同时验证这个限制，不能仅依据 C 编译是否成功判断镜像可正常启动。

## 8. 代码目录导览

| 路径 | 作用 |
| --- | --- |
| `boot/boot.asm` | BIOS 软盘引导扇区；读取 loader 和内核 |
| `boot/loader.asm` | 检查 VBE 模式信息、保存图形字体、设置 GDT 并进入保护模式 |
| `kernel/entry.asm` | 内核入口、BSS 清零以及保护模式与 BIOS 视频调用之间的切换 |
| `kernel/kernel.c` | 内核主逻辑：VGA 终端、输入、桌面、窗口、应用和命令表 |
| `kernel/fat12.c` | FAT12 相关实现 |
| `kernel/fat32.c`、`kernel/fat32.h` | FAT32 挂载、目录和文件操作接口 |
| `kernel/ide.c` | IDE 磁盘访问 |
| `kernel/process.c`、`kernel/process.h` | 进程表和简单调度逻辑 |
| `kernel/link.ld` | 内核链接地址和段布局 |
| `programs/` | 可由构建系统编译的示例用户程序 |
| `Makefile` | NASM、GCC、链接、镜像创建、清理和 QEMU 运行规则 |
| `docs/` | 项目补充文档和更新记录 |

## 9. 当前范围与限制

- 这是用于学习和实验的 32 位 x86 原型，主要在 QEMU BIOS 环境中验证。
- 图形桌面依赖 VBE 1024 × 768 × 24 位模式；不提供通用显卡驱动或任意显示器模式协商。
- 桌面是轮询式事件循环，应用窗口共享内核执行环境；不是独立进程、抢占式 GUI，也不具备窗口崩溃隔离。
- GUI 文本输入以可打印 ASCII 为主；没有 Unicode/中文输入法、剪贴板、字体管理或完整的文本排版。
- Editor 和 Terminal 的单窗口缓冲区有固定容量；Editor 关闭时不提示未保存内容。
- FAT32 实现服务于项目的基本文件操作，不承诺支持所有 FAT32 扩展、长文件名或复杂磁盘布局。
- 当前没有网络栈、声音系统、USB 驱动、现代显卡驱动、用户账户和安全权限模型。
- GUI Terminal 不等同于完整 shell；对需要交互输入或直接访问 VGA 的命令，应使用文本 CLI。

## 10. 测试与故障排查

### `make` 报告找不到 `build/` 输出目录

当前 Makefile 会在构建时自动创建 `build/`。若仍遇到该问题，请确认在仓库根目录执行 `make`，并检查文件权限和 Makefile 是否为本工作树中的版本。

### `make run` 报告找不到 `hdd.img`

正常情况下，运行目标会自动创建 32 MiB FAT32 数据盘。检查是否安装了 `dosfstools`，以及当前目录是否可写。已有的 `hdd.img` 会被保留。

### VNC 无法连接或画面未出现

确认 QEMU 已经启动，并连接 `localhost:5901`。若系统停在启动错误提示，检查 QEMU 是否以 BIOS 兼容方式启动、启动软盘是否为本次构建的 `cl_os.img`，以及模拟器是否提供所需 VBE 模式信息。

### GUI 返回 CLI 后画面异常

GUI 退出路径会重新设置 VGA 文本模式并清屏。可用 **EXIT TO CLI** 返回；随后确认屏幕恢复文本 CLI，再输入 `shut` 关机。Esc 用于关闭当前应用窗口，不用于直接离开桌面。

### 内核容量超限

链接时 Makefile 会检查 124 扇区限制。若扩展引导加载量，必须同步核对 `boot/boot.asm` 的 CHS 读取区段、软盘容量、DMA 边界以及 `Makefile` 中的最大字节检查，并在 QEMU 中验证完整启动；不能只修改大小常量。
